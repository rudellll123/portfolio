AegisAI: incident investigation platform

Answers questions about an incident from stored evidence, using video, logs and documents.

  • Python framework built on FastAPI, PostgreSQL and LangGraph that gives agents the right tools for each case.
  • Hybrid RAG: Qdrant vector search and BM25, merged with Reciprocal Rank Fusion and re-ranked by a cross-encoder.
  • Video pipeline with YOLOv8 and ByteTrack, run asynchronously through Celery and Redis, with automated evaluation and GitHub Actions CI.
